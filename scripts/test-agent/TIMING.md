# 時間の計測点（定義）

1往復にかかる時間を分解して測るための定義。**起点と終点をここで固定し、認識がぶれないようにする。**

## 1往復の流れ（外国語のお客様の場合）

```
係員が話す ──T1── 話し終わり ──T2── 係員画面に日本語 ──T3── 送信
                                                          ├─T4─→ お客様画面に文字
                                                          └─T5─→ 最初の音声 ──T6── 最後の音声
                                                                    └──T7── 読み上げ終わり
                                                                              ↓
                                                                      ［お客様が考える］
お客様が話す ──T8── 話し終わり ──T9── 認識が確定 ──T10── 送信 ──T11── 係員画面に原文＋日本語訳
                                                                              ↓
                                                                       ［係員が考える］
```

## 計測点の定義

| 記号 | 名前 | 起点（この瞬間から） | 終点（この瞬間まで） | 翻訳の有無で変わるか |
|---|---|---|---|---|
| **T1** | 係員の発話時間 | 係員が話し始めた瞬間 | 係員が話し終えた瞬間 | 変わらない |
| **T2** | 係員側の音声認識 | 係員が話し終えた瞬間 | 係員画面に確定した日本語が出た瞬間 | 変わらない |
| **T3** | 送信までの処理 | 係員画面に確定が出た瞬間 | 係員端末が発言を送り出した瞬間 | 変わらない |
| **T4** | お客様画面に文字が出るまで | 係員端末が発言を送り出した瞬間 | お客様の端末に文字が届いた瞬間 | **変わる** |
| **T5** | 最初の音声が届くまで | 係員端末が発言を送り出した瞬間 | お客様の端末に1つ目の音声が届いた瞬間 | **変わる** |
| **T6** | 音声を受け取り終わるまで | 1つ目の音声が届いた瞬間 | 最後の音声が届いた瞬間 | 少し変わる |
| **T7** | アバターの読み上げ時間 | 読み上げの開始 | 読み上げの終了 | 変わらない（合成音声の長さ） |
| **T8** | お客様の発話時間 | お客様が話し始めた瞬間 | お客様が話し終えた瞬間 | 変わらない |
| **T9** | お客様側の音声認識 | お客様が話し終えた瞬間 | 認識が確定した瞬間 | 変わらない |
| **T10** | 送信までの処理 | 認識が確定した瞬間 | 端末が係員へ送り出した瞬間 | 変わらない |
| **T11** | 係員画面に文字が出るまで | 端末が係員へ送り出した瞬間 | 係員画面に原文と日本語訳が出た瞬間 | **変わる** |

## 用語をそろえるための注意

- **「話し終えた瞬間」** … 声を出し終えた瞬間。自動テストでは音声データを送り終えた時刻。
  マイクを切った時刻ではない（切るのは数秒後になるため）。
- **「確定」** … 音声認識が「ここまでで1文が決まった」と返した時点。
  話している最中に出る途中経過（interim）は含まない。途中経過は確定より約2〜3秒早く出る。
- **「送り出した瞬間」** … 端末がサーバーへ発言を送信した時刻。相手に届いた時刻ではない。
- **T4とT5は同じ起点** から測る別々の終点。どちらが先に着くかは、文字が先（設計上そうしている）。
- **T6が0秒** のときは、返答が短くて音声が1つに収まったということ。分割再生の出番が無かった状態。

## 翻訳の有無による場合分け

| | 翻訳が入る区間 |
|---|---|
| **日本語のお客様** | なし（T4・T5・T11に翻訳の時間は含まれない） |
| **外国語のお客様** | T4・T5（日本語→外国語）、T11（外国語→日本語） |

**この2つは必ず分けて集計する。** 混ぜると翻訳の時間が薄まって見え、対策の判断を誤る。

## 合計の出し方

- **機械が使っている時間** ＝ T2＋T3＋T5＋T9＋T10＋T11
  （T4はT5とほぼ同時なので二重に数えない。T6は音声が届き切るまでで、読み上げと重なる）
- **1往復にかかる時間** ＝ T1＋機械の時間＋T7＋［お客様が考える時間］＋T8＋機械の時間＋［係員が考える時間］
- **人が考える時間は測れない。** 自動テストの数字には含まれない。

## 測っていないもの

- 人が理解して次の言葉を考える時間（お客様側・係員側とも）
- 実機の画面描画にかかる時間（測定はサーバーとの通信の時刻で行っている）
- 係員が発言を送るまでの操作の時間（実際はマイクを切る操作などが入る）
