# 自動シナリオテスト（AIがお客様と係員の両方を務める）

窓処端末のブラウザを使わずに、**本番とまったく同じ通信の道**を通して8言語の通話を自動で流し、
遅延・安定性・用語集の効き目を測る道具です。

## いちばん大事なこと

**疑似係員が一般のお客様の呼び出しを取ってしまうと、そのお客様は誰にもつながりません。**
安全装置を3つかけてあります。ひとつでも外さないでください。

| 段 | 仕組み | 場所 |
|---|---|---|
| ① | 担当駅をテスト専用の駅IDだけにする | `run.mjs` が `TEST_STATION_ID` を渡す |
| ② | **端末名・端末IDが `test-` で始まらない着信には絶対に応答しない** | `config.mjs` の `isTestCall()` |
| ③ | 着信を受けたら即座に応答する（人が取る前に片づける） | `fake-staff.mjs` |

②がいちばん重要です。サーバーは「駅の指定が無い呼び出しは全係員に配る」作りなので
（`server/socketServer.ts:207`）、①だけでは一般の呼び出しが届く可能性が残ります。

**終わったら疑似係員を必ず止めてください。** 生き残ると本番の待機一覧に残り続けます。
`run.mjs` は Ctrl+C や異常終了でも止めますが、最後に本番の待機一覧を目視で確認してください。

## 使い方

### 1. 台本を作る／直す

```bash
node scripts/test-agent/make-scenarios.mjs
```

`make-scenarios.mjs` の中の台詞・駅名を編集してから実行すると、`scenarios/*.json` が作り直されます。

### 2. 台本を自己検査する（ネイティブ確認の代わり）

```bash
GOOGLE_API_KEY=... node scripts/test-agent/check-scenarios.mjs
```

外国語の台詞を日本語に逆翻訳し、意図とずれていないか見ます。
**分かるのは「意味が通じるか」まで。「現地で自然な言い方か」は分かりません。**

### 3. 音声を作る

```bash
GOOGLE_API_KEY=... node scripts/test-agent/make-audio.mjs --lang all
```

読み上げさせたあと、必ず劣化（帯域を絞る・音量を下げる・雑音を混ぜる）をかけます。
`NOISE_DB`（既定 -26）と `VOICE_GAIN`（既定 0.55）で調整できます。

### 4. 流す

```bash
# 開発環境（既定）
TEST_TARGET=dev TEST_STATION_ID=test-lab SESSION_SECRET=... \
  node scripts/test-agent/run.mjs --lang all

# 本番（TEST_CONFIRM=yes が無いと動かない）
TEST_TARGET=prod TEST_CONFIRM=yes TEST_STATION_ID=test-lab SESSION_SECRET=... \
  node scripts/test-agent/run.mjs --lang ja --scenario 01
```

`--lang` は言語コードか `all`、`--scenario` でシナリオを1本だけにできます。
結果は `out/run-<日時>.json` に残ります。

### 5. 採点する

```bash
node scripts/test-agent/score.mjs --csv
```

言語別に、用語集ありの駅名の正解率／なしの正解率／返答の到達／遅延／障害をまとめます。

## 結果の読み方（重要）

テスト音声は機械の声です。人の声より認識されやすいため、**認識精度の数字は実際より良く出ます。**

| 信用してよい | 参考程度 |
|---|---|
| 遅延（音声の質にほぼ左右されない） | 認識精度の絶対値 |
| 落ちない・切れない安定性 | 「何%認識できる」という一般的な数字 |
| 用語集が効いているか（誤って届いた駅名の一覧） | ― |

認識精度は**前回との比較**に使ってください。絶対値はネイティブの方によるテストで確認します。

外国語の台本はネイティブの確認を受けていません。言い回しが不自然な可能性があります。

## 本番で流すときの決まり

- **用語集を触らない**（全員で共有していて、5分ほどで全通話に反映されます）
- **本番反映（デプロイ）をしない**（通話が切れ、版番号が混ざります）
- **1通話ずつ順番に**（同時にはしない）
- 言語の切れ目で一旦止めて様子を見る
- ログとCSVは言語ごとにその場で保存する（Railwayは入れ替え前のログを持ちません）
- 他の係員の画面にテストの着信が出た／一般の通話が切れた → **その場で全部止める**

## ファイル

| ファイル | 役割 |
|---|---|
| `config.mjs` | 宛先・言語・音声の形・**安全装置の判定** |
| `fake-kiosk.mjs` | 疑似お客様（音声を実時間で流し込む） |
| `fake-staff.mjs` | 疑似係員（即応答・台本どおりに返事） |
| `run.mjs` | 進行役（通話を1本ずつ回す・必ず後片付けする） |
| `make-scenarios.mjs` | 台本づくり |
| `check-scenarios.mjs` | 台本の自己検査（逆翻訳） |
| `make-audio.mjs` | 音声づくり（読み上げ＋劣化） |
| `score.mjs` | 採点 |
